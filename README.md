## 📌 Descripción del Proyecto

Este repositorio contiene la resolución de los ejercicios de la **Fase 1 de Programación Orientada a Objetos (POO)**, enfocados en la aplicación de clases, constructores, arreglos de objetos y control de flujo en **Java**.

---

## 📂 Ejercicios Desarrollados

A continuación se enlistan los códigos prácticos implementados en este repositorio:

| Archivo | Descripción del Ejercicio / Lógica POO | Estado |
| :--- | :--- | :---: |
| 📄 **Ejercicio1.java** | Gestión de estudiantes, cálculo de promedios y clasificación de notas | ✅ Completado |
| 📄 **Ejercicio2.java** | Control de inventario de productos, stock y alertas de reposición | ✅ Completado |
| 📄 **Ejercicio3.java** | Registro de mascotas, atributos, pesos y referencias de objetos | ✅ Completado |
| 📄 **Ejercicio4.java** | Simulación de cuentas bancarias y acumulación de saldos por mes | ✅ Completado |
| 📄 **Ejercicio5.java** | Gestión de biblioteca, libros disponibles y control de socios | ✅ Completado |
